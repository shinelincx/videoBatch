# 杂项

一些偶尔会用到的工具。

- **[git-guardrails-claude-code](./git-guardrails-claude-code/SKILL.md)** — 为 Claude Code 设置钩子，在执行前拦截危险的 Git 命令（push、reset --hard、clean 等）。
- **[migrate-to-shoehorn](./migrate-to-shoehorn/SKILL.md)** — 将测试文件中的 `as` 类型断言迁移到 @total-typescript/shoehorn。
- **[scaffold-exercises](./scaffold-exercises/SKILL.md)** — 创建练习目录结构，包含章节、练习题、解决方案和说明文档。
- **[setup-pre-commit](./setup-pre-commit/SKILL.md)** — 配置 Husky pre-commit 钩子，集成 lint-staged、Prettier、类型检查和测试。
