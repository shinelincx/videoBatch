# 参考文档

## 各模块详细规范

### 标题

标题是决定点击率的核心元素。每次生成 3-5 个备选，覆盖以下三种模式：

| 模式 | 特征 | 示例 |
|------|------|------|
| 标题党 | 制造好奇、夸张对比、数字量化 | "99%的人不知道的XX技巧，3天见效" |
| 直给型 | 直接告知内容价值，适合搜索流量 | "2024年XX选购指南：这些坑别再踩" |
| 悬念型 | 引发好奇心，提高完播率 | "我花了3个月测试了所有XX，结果出乎意料" |

标题生成规则：
- 抖音/快手：控制在 15-25 字，含 1-2 个 emoji
- 视频号：8-15 字，偏正式表达
- B 站：可扩展至 30 字，支持双标题模式

### 口播脚本

按时间轴分段，每段包含：

```
[00:00-00:05] 钩子（Hook）
情绪：惊讶/好奇
口播："..."

[00:05-00:20] 痛点/场景引入
情绪：共鸣/认同
口播："..."

[00:20-00:40] 产品展示/价值输出
情绪：专业/热情
口播："..."

[00:40-00:55] 信任背书/使用效果
情绪：坚定/真诚
口播："..."

[00:55-01:00] CTA
情绪：引导/期望
口播："..."
```

分段数量依据视频时长动态调整：
- 15s：3 段（钩子 → 核心卖点 → CTA）
- 30s：4 段（钩子 → 痛点 → 卖点 → CTA）
- 60s：5-6 段（钩子 → 痛点 → 卖点 → 背书 → 优惠 → CTA）
- 120s+：按 20s 一段拆分，扩展故事线

### 字幕文本

> **适用模式**：对话模式。API 模式字幕规则见 [PRD.md](../../../docs/specs/copywriting-agent/PRD.md) F2。

字幕要求：
- 每段不超过 20 个字（单屏显示上限）
- 与口播语义一致但更精简
- 关键词高亮（用 `**粗体**` 标注需放大/彩色显示的字）— **注意**：SRT 输出格式不支持 Markdown 标记，此项仅适用于对话模式 Markdown 输出
- 节拍控制：每段字幕展示时长与口播对应段落的时长一致

### 推荐标签

按三级流量池策略生成：

| 流量池 | 数量 | 类型 | 示例 |
|--------|------|------|------|
| 大流量池 | 2-3 个 | 泛话题、高搜索量 | #好物推荐 #知识分享 |
| 精准池 | 3-4 个 | 品类/人群精准定位 | #敏感肌护肤 #宝妈好物 |
| 长尾池 | 2-3 个 | 场景/痛点细分 | #换季过敏怎么办 |

### CTA

CTA 话术四要素：
1. **价值承诺**（为什么要做）
2. **行动指令**（做什么）
3. **低门槛提示**（怎么做很简单）
4. **稀缺感/紧迫感**（为什么现在做）

示例模板：
> "如果你也想[价值承诺]，[行动指令]！[低门槛提示]，[紧迫感]。"

## 平台适配速查

| 平台 | 黄金时长 | 语速 | 文案调性 | 关键规则 |
|------|----------|------|----------|----------|
| **抖音** | 15-60s | 中快 | 节奏感强，前 3 秒必须有钩子 | 完播率 > 点赞率，前 3 秒定生死 |
| **快手** | 30-90s | 中 | 接地气，强调"老铁""家人们" | 信任感建立，1 分钟以上视频权重高 |
| **视频号** | 30-60s | 中慢 | 偏正式/知识型，少用网络梗 | 社交裂变优先，话题需有转发价值 |
| **B 站** | 60-180s | 中 | 可深入分析，允许长文案 | 弹幕互动重要，预留互动引导点 |
| **小红书** | 15-30s | 中快 | 精致/种草风，图文搭配 | 标签精准，封面图比标题更重要 |

## TTS 输出规范

> **适用模式**：对话模式及降级参考。API 模式通过多引擎适配层合成配音，详情见 [PRD.md](../../../docs/specs/copywriting-agent/PRD.md) F3。

### 纯文本口播格式

去除所有标记、时间戳、情绪提示后的纯朗读文本，用 `|` 标记自然停顿：

```
你想过没有 | 为什么同样是护肤 | 有些人的皮肤就是比你好 | 其实秘密不在于用了多贵的护肤品 | 而在于一个你每天都在做 | 却做错了的动作
```

### 语速建议

| 平台 | 语速（字/分钟） | 对应 TTS speed 参数 |
|------|-----------------|---------------------|
| 抖音/快手 | 300-350 | 1.1x - 1.2x |
| 视频号 | 250-280 | 1.0x |
| B 站 | 260-300 | 1.0x - 1.1x |
| 小红书 | 320-360 | 1.2x |

### 停顿时长建议

| 停顿类型 | 符号 | 建议时长 |
|----------|------|----------|
| 句子停顿 | `|` | 300ms |
| 段间停顿 | `||` | 600ms |
| 场景转换 | `|||` | 1000ms |
| 情绪转折 | （空行） | 1200ms |

## 领域词汇合规

生成文案时严格遵守 `CONTEXT.md` 中定义的术语：

- 使用 **文案（Copywriting）**，不用 "营销文本"、"AI 文案"、"旁白"
- 涉及视频制作时使用 **剪辑（Editing）**，不用 "视频处理"、"后期制作"
- 提及输出文件使用 **视频（Video）**，不用 "成品"、"输出文件"
- 涉及音频部分使用 **配音（MP3）**，不用 "语音合成"、"AI 配音"

## 防重策略

当批量生成多条文案时，启用以下随机变化避免内容重复：

| 变化维度 | 实现方式 |
|----------|----------|
| 钩子句式 | 从 6 种句式模板中随机（反问式/数据式/场景式/对比式/悬念式/情绪式） |
| 过渡词库 | 每个衔接位置从备选词库中随机抽取 |
| CTA 变体 | 每次从 8 种 CTA 模式中轮询 |
| 标签组合 | 大类标签不变，长尾标签从词库随机替换 |
