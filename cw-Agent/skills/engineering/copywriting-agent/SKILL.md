# 短视频营销文案智能体

此 skill 根据视频素材信息生成结构化营销文案，覆盖主流短视频平台。全程使用项目领域词汇表（`CONTEXT.md`）中的术语，遵守涉及的 ADR。

## 双模式

此 skill 支持两种使用方式：

| 模式 | 入口 | 输出 |
|------|------|------|
| 对话模式 | 对话触发（流程步骤 1-5） | Markdown 结构化文案 |
| API 模式 | `POST /api/v2/copywriting/generate` | SRT 字幕 + MP3 配音 |

> API 模式详情见 [PRD.md](../../../docs/specs/copywriting-agent/PRD.md)，包含完整的接口规范、技术架构、领域模型。

## 触发条件（对话模式）

- "帮我写一段文案"
- "生成营销文案"
- "给这个视频写个脚本"
- "生成带货话术"
- "生成 TTS 口播"

## 流程

### 1. 收集素材信息

向用户确认以下输入（至少需要前两项）：

| 输入项 | 必填 | 说明 |
|--------|------|------|
| 产品/主题 | ✅ | 视频要推广的产品、服务或话题 |
| 核心卖点 | ✅ | 2-5 个关键卖点或信息点 |
| 目标平台 | ❌ | 抖音/快手/视频号/B站（默认：抖音） |
| 目标人群 | ❌ | 年龄段、消费偏好等（默认：泛人群） |
| 视频时长 | ❌ | 秒数（默认：60s） |
| 风格偏好 | ❌ | 见下方风格列表（默认：情感共鸣型） |

### 2. 确认风格

让用户从以下风格中选择，或用自然语言描述：

| 风格 | 适用场景 |
|------|----------|
| 情感共鸣型 | 生活方式、母婴、教育、情感类产品 |
| 紧迫促销型 | 限时折扣、直播带货、爆款秒杀 |
| 专业种草型 | 数码评测、美妆护肤、知识付费 |
| 幽默引流型 | 泛娱乐、搞笑号、引流涨粉 |
| 痛点解决型 | 工具软件、健康养生、效率提升 |
| 悬念反转型 | 剧情号、品牌故事、高完播率内容 |

### 3. 生成结构化文案

按以下结构输出（见 [REFERENCE.md](REFERENCE.md) 每个模块的详细规范）：

```markdown
## 文案输出

### 基本信息
- 产品/主题：
- 核心卖点：
- 目标平台：
- 文案风格：
- 预估时长：

### 1. 标题（3-5 个备选）
涵盖标题党/直给型/悬念型三种模式

### 2. 口播脚本
按时间轴分段的完整口播文案，每段标注时间戳和情绪提示

### 3. 字幕文本
与口播对应的精简字幕，适合屏幕叠加显示

### 4. 推荐标签（5-10 个）
平台话题标签组合

### 5. CTA（行动号召）
引导用户点赞/关注/点击链接的具体话术
```

### 4. 优化迭代

向用户展示文案后询问是否需要调整：
- 缩短/延长时长
- 更换风格
- 调整某段话术
- 增加特定关键词（SEO/平台热词）

### 5. TTS 输出（可选）

如果用户要求生成配音（MP3），输出以下格式供 TTS 引擎使用：
- 纯文本口播（去除标记的纯朗读文本）
- 语速建议（快/中/慢，对应不同平台调性）
- 停顿标记（自然断句位置）
