# Deep Modules（深层模块）

来自《软件设计的哲学》：

**深层模块** = 小接口 + 大量实现

```
┌─────────────────────┐
│   小型接口           │  ← 方法少，参数简单
├─────────────────────┤
│                     │
│                     │
│  深层实现            │  ← 复杂逻辑被隐藏
│                     │
│                     │
└─────────────────────┘
```

**浅层模块** = 大接口 + 少量实现（避免）

```
┌─────────────────────────────────┐
│       大型接口                   │  ← 方法多，参数复杂
├─────────────────────────────────┤
│  薄实现                           │  ← 只是透传
└─────────────────────────────────┘
```

设计接口时，问自己：

- 能不能减少方法数量？
- 能不能简化参数？
- 能不能在内部隐藏更多复杂度？
