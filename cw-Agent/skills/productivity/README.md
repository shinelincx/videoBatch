# 生产力工具（Productivity）

通用工作流工具，不涉及代码。

- **[caveman](./caveman/SKILL.md)** — 极简通信模式。通过去除冗余内容同时保持技术准确性，降低约 75% 的 token 用量。
- **[grill-me](./grill-me/SKILL.md)** — 对方案或设计进行高强度追问，直到决策树的每个分支都被厘清。
- **[handoff](./handoff/SKILL.md)** — 将当前对话压缩成交接文档，供其他 agent 继续工作。
- **[write-a-skill](./write-a-skill/SKILL.md)** — 创建新 skill，包含合理的结构、渐进式信息披露和配套资源。
