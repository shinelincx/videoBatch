# 电商文案智能体 — 用户操作手册

---

## 1. 系统概述

**电商文案智能体（CW-Agent）** 是一款基于大语言模型（LLM）的电商营销文案自动生成工具。输入产品信息后，系统自动生成平台定制的营销口播文案，并同步合成 TTS 语音和 SRT 字幕文件。

### 核心功能

| 功能 | 说明 |
|------|------|
| 文案生成 | 支持 5 大平台、20+ 品类、12 种语言的营销文案自动生成 |
| 智能路由 | 自动匹配平台 × 品类的最佳文案策略（Skill），每套策略含定制执行步骤、质量标准、禁用词等 |
| 知识库增强 | 检索高赞参考文案与通用句式模板，提升文案质量 |
| 趋势知识增强 | 摄入抖音实时热门视频数据，检索趋势洞察并注入 Prompt，提升文案时效性 |
| 字数校验 | 智能估算目标字数，超出 ±15% 偏差则自动重试（最多 3 次） |
| TTS 语音合成 | 基于微软 Edge-TTS，100+ 种神经网络语音，支持情感分析自动调节语速音调 |
| SRT 字幕生成 | 多语种语义断句，字幕随音频播放实时高亮 |
| Web 界面 | 可视化操作界面，表单填写 → 一键生成 → 在线预览 |
| CLI 工具 | 命令行一键生成，适合批量/脚本集成 |
| v2 仅文案 API | 轻量接口，仅生成文案正文 + Token 用量统计，不含音频/字幕 |
| 自动清理 | 超过 24 小时的输出文件自动清理 |
| Token 认证 | 可选的 API 认证机制，支持创建/撤销 Token，保障接口安全 |

## 2. 环境准备与安装

### 2.1 系统要求

- Python 3.10+
- 稳定的网络连接（需访问 LLM API 和微软 TTS 服务）

### 2.2 安装步骤

```bash
# 1. 克隆或进入项目目录
cd cw-Agent

# 2. 安装 Python 依赖
pip install -r requirements.txt
```

主要依赖包括：
- `fastapi` + `uvicorn`：Web 服务框架
- `langchain` + `langchain-openai` + `langchain-community`：LLM 调用框架
- `edge-tts`：微软 Edge TTS 语音合成
- `pydantic`：数据模型校验
- `python-dotenv`：环境变量加载
- `python-multipart`：表单/文件上传支持
- `oss2`：阿里云 OSS SDK（OSS 上传功能依赖）

### 2.3 配置文件

复制环境变量模板并填入实际的 API Key：

```bash
cp .env.example .env
```

编辑 `.env` 文件：

```ini
LLM_API_KEY=sk-your-api-key-here
LLM_BASE_URL=https://api.deepseek.com
LLM_MODEL=deepseek-chat
VISION_LLM_API_KEY=sk-your-vision-api-key-here
VISION_LLM_BASE_URL=https://api.openai.com/v1
VISION_LLM_MODEL=gpt-4o-mini
OSS_ENABLED=false
OSS_ACCESS_KEY_ID=your-oss-access-key-id
OSS_ACCESS_KEY_SECRET=your-oss-access-key-secret
OSS_ENDPOINT=https://oss-cn-hangzhou.aliyuncs.com
OSS_BUCKET_NAME=your-bucket-name
OSS_OBJECT_PREFIX=cw-agent
OSS_SIGNED_URL_EXPIRES=86400
OSS_PUBLIC_BASE_URL=
TTS_PROVIDER=edge_tts
DEFAULT_LANGUAGE=zh
# 可选配置
# AUTH_ENABLED=true
# EMOTION_ENABLED=true
# ENABLE_KNOWLEDGE=true
# MAX_KNOWLEDGE_REFS=3
# KNOWLEDGE_DIR=knowledge
# DEFAULT_SKILL=通用_通用_基础
# ENABLE_TREND_KNOWLEDGE=true
# MAX_TREND_REFS=3
# TREND_DB_PATH=data/trends.sqlite3
# TREND_API_TOKEN=your-trend-api-token
```

| 变量 | 必填 | 说明 |
|------|------|------|
| `LLM_API_KEY` | 是 | LLM API 密钥 |
| `LLM_BASE_URL` | 否 | API 地址，默认 `https://api.openai.com/v1` |
| `LLM_MODEL` | 否 | 模型名称，默认 `gpt-4o-mini` |
| `VISION_LLM_API_KEY` | 图片模式必填 | 图片理解模型 API 密钥 |
| `VISION_LLM_BASE_URL` | 图片模式必填 | 图片理解模型 API 地址 |
| `VISION_LLM_MODEL` | 图片模式必填 | 支持图片输入的多模态模型名称 |
| `OSS_ENABLED` | 否 | 是否将生成的音频和字幕上传到阿里云 OSS，默认 `false` |
| `OSS_ACCESS_KEY_ID` | OSS 启用时必填 | 阿里云 AccessKey ID |
| `OSS_ACCESS_KEY_SECRET` | OSS 启用时必填 | 阿里云 AccessKey Secret |
| `OSS_ENDPOINT` | OSS 启用时必填 | OSS Endpoint，例如 `https://oss-cn-hangzhou.aliyuncs.com` |
| `OSS_BUCKET_NAME` | OSS 启用时必填 | OSS Bucket 名称 |
| `OSS_OBJECT_PREFIX` | 否 | OSS 对象前缀，默认 `cw-agent` |
| `OSS_SIGNED_URL_EXPIRES` | 否 | 私有 Bucket 签名下载链接有效期（秒），默认 `86400` |
| `OSS_PUBLIC_BASE_URL` | 否 | 公共访问域名或 CDN 域名；配置后返回公开链接，否则返回签名链接 |
| `TTS_PROVIDER` | 否 | TTS 引擎，目前仅支持 `edge_tts` |
| `DEFAULT_LANGUAGE` | 否 | 默认语言，默认 `zh` |
| `EMOTION_ENABLED` | 否 | 是否启用情感分析，默认 `true` |
| `ENABLE_KNOWLEDGE` | 否 | 是否启用知识库检索，默认 `true` |
| `MAX_KNOWLEDGE_REFS` | 否 | 知识库最大引用条目数，默认 `3` |
| `KNOWLEDGE_DIR` | 否 | 知识库目录路径，默认 `knowledge` |
| `DEFAULT_SKILL` | 否 | 兜底 Skill 名称，默认 `通用_通用_基础` |
| `ENABLE_TREND_KNOWLEDGE` | 否 | 是否启用趋势知识增强（实时热门视频洞察），默认 `true` |
| `MAX_TREND_REFS` | 否 | 趋势知识最大引用条目数，默认 `3` |
| `TREND_DB_PATH` | 否 | 趋势数据库路径，默认 `data/trends.sqlite3` |
| `TREND_API_TOKEN` | 否 | 趋势数据摄入 API 的鉴权 Token，为空则不校验 |
| `AUTH_ENABLED` | 否 | 是否启用 Token 认证，默认 `false` |
| `TOKEN_FILE` | 否 | Token 存储文件路径，默认 `tokens.json` |

## 3. Web 界面使用指南

### 3.1 启动服务

```bash
python main.py
```

服务启动后，浏览器访问 **`http://localhost:8700`**。

### 3.2 界面布局

界面采用左右双栏布局：

- **左侧**：输入表单
- **右侧**：生成结果展示（文案、统计、音频播放、字幕列表）

### 3.3 表单字段说明

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| Token | 输入框 | API 认证 Token（AUTH_ENABLED 时必填） | `cw-a1b2c3...` |
| 品类 | 输入框 | 产品所属品类 | `美妆`、`数码`、`食品`、`服饰` |
| 标题 | 输入框 | 产品名称/标题 | `保湿面霜` |
| 关键词 / 卖点 | 文字或图片 | 文字模式下逗号分隔；图片模式下上传商品图，由图片理解模型提取关键词 | `补水,锁水,清爽不油腻` |
| 时长 | 数字 | 目标文案朗读时长，15-180 秒 | `30` |
| 平台 | 下拉框 | 投放平台 | `抖音`、`淘宝`、`小红书`、`TikTok`、`Amazon` |
| 风格 | 下拉框 | 文案风格 | `简洁`、`热情`、`幽默`、`温情`、`热血` |
| 语言 | 下拉框 | 输出语言（切换后声音列表自动更新） | `简体中文（zh）` |
| 声音 | 下拉框 | TTS 音色，语言切换后动态加载 | `晓晓（女·普通话）` |

### 3.4 操作流程

1. **填写表单**：依次填入产品品类、标题，并选择文字或图片关键词模式
   - 文字模式：手动输入卖点，使用逗号分隔
   - 图片模式：上传 1-6 张商品图片，支持 JPG / PNG / WebP，单张不超过 8MB
2. **选择平台与风格**：根据投放目标选择合适的平台和文案风格
3. **选择语言与声音**：选择目标语言后，声音列表自动加载
4. **点击"生成文案"**：等待数秒（生成过程中显示加载动画）
5. **查看结果**：
   - **生成文案卡片**：展示标题、标签和正文
   - **统计信息**：显示字数和预计时长
   - **音频播放器**：在线播放生成的 TTS 音频
   - **当前字幕**：音频播放时实时显示当前字幕内容
   - **字幕列表**：完整字幕时间轴，当前字幕高亮显示

### 3.5 音频与字幕联播

- 播放音频时，**当前字幕卡片**实时显示对应的字幕内容
- **字幕列表**中当前条目自动高亮，支持滚动查看全量字幕
- 点击字幕列表项可查看完整时间戳信息

## 4. CLI 命令行使用指南

### 4.1 基本用法

```bash
python cli.py -c <品类> -t <标题> -s <卖点> [-d <时长>] [-p <平台>] [-o <风格>] [-l <语言>] [-v <声音>]
```

### 4.2 参数说明

| 参数 | 简写 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `--category` | `-c` | 是 | - | 产品品类 |
| `--title` | `-t` | 是 | - | 产品标题 |
| `--selling-points` | `-s` | 是 | - | 核心卖点，逗号分隔 |
| `--duration` | `-d` | 否 | `30` | 目标文案时长（秒） |
| `--platform` | `-p` | 否 | `抖音` | 投放平台 |
| `--tone` | `-o` | 否 | `简洁` | 文案风格 |
| `--language` | `-l` | 否 | `zh` | 输出语言 |
| `--voice` | `-v` | 否 | `""`（语种默认） | TTS 音色 ShortName |
| `--output-dir` | 否 | `./output` | 输出目录 |
| `--token` | 否 | `None` | 授权 Token（也可通过环境变量 `AUTH_TOKEN` 设置） |

### 4.3 使用示例

**示例 1：基础用法**

```bash
python cli.py -c 美妆 -t "保湿面霜" -s "补水,锁水,清爽不油腻"
```

**示例 2：指定平台和风格**

```bash
python cli.py -c 美妆 -t "保湿面霜" -s "补水,锁水,清爽不油腻" -d 30 -p 抖音 -o 热情 -l zh
```

**示例 3：指定音色**

```bash
python cli.py -c 美妆 -t "保湿面霜" -s "补水,锁水,清爽不油腻" -l zh -v "zh-CN-YunxiNeural"
```

**示例 4：英文文案**

```bash
python cli.py -c Beauty -t "Moisturizing Cream" -s "Hydrating,Lightweight,Natural" -d 60 -p TikTok -o Professional -l en
```

### 4.4 输出文件

CLI 执行成功后，在 `output/` 目录生成以下文件：

| 文件 | 路径格式 | 说明 |
|------|----------|------|
| 音频 | `output/audio_YYYYMMDD_HHMMSS.mp3` | TTS 合成音频 |
| 字幕 | `output/subtitle_YYYYMMDD_HHMMSS.srt` | 标准 SRT 字幕文件 |

控制台同时输出文案正文、字数和预估时长。

## 5. API 接口说明

服务启动后，API 基础路径为 `http://localhost:8700`。

### 5.1 生成文案（v1，含音频/字幕）

**`POST /api/generate`**

> 当 `AUTH_ENABLED=true` 时，需携带 `Authorization: Bearer <token>` 请求头。

请求体（JSON）：

```json
{
  "category": "美妆",
  "title": "保湿面霜",
  "selling_points": ["补水", "锁水", "清爽不油腻"],
  "duration": 30,
  "platform": "抖音",
  "tone": "热情",
  "language": "zh",
  "voice": "zh-CN-XiaoxiaoNeural",
  "tags": ["护肤", "秋冬"]
}
```

响应体（AgentResponse）：

```json
{
  "input": { ... },
  "marketing_copy": {
    "title": "...",
    "tags": ["..."],
    "text": "...",
    "word_count": 120,
    "estimated_duration": 28.5
  },
  "audio": {
    "file_path": "output/20260101_120000_audio.mp3",
    "format": "mp3",
    "duration": 29.2,
    "download_url": "https://example.oss-cn-hangzhou.aliyuncs.com/cw-agent/20260101_120000_audio.mp3"
  },
  "subtitle": {
    "srt_file_path": "output/20260101_120000_subtitle.srt",
    "download_url": "https://example.oss-cn-hangzhou.aliyuncs.com/cw-agent/20260101_120000_subtitle.srt",
    "entries": [
      {
        "index": 1,
        "start_time": "00:00:00,000",
        "end_time": "00:00:02,500",
        "text": "..."
      }
    ]
  },
  "skill_info": {
    "skill_name": "抖音_美妆_带货",
    "match_type": "exact",
    "matched_by": "抖音+美妆",
    "skill_description": "抖音美妆带货口播文案..."
  }
}
```

### 5.2 图片关键词模式生成文案（v1）

**`POST /api/generate/images`**

> 当 `AUTH_ENABLED=true` 时，需携带 `Authorization: Bearer <token>` 请求头。该接口使用 `multipart/form-data`，后端会先调用视觉模型提取关键词，再进入普通文案生成流程。

表单字段：

| 字段 | 必填 | 说明 |
|------|------|------|
| `category` | 是 | 产品品类 |
| `title` | 是 | 产品标题 |
| `images` | 是 | 商品图片，可多张，最多 6 张，单张不超过 8MB |
| `duration` | 否 | 目标文案时长，默认 30 |
| `platform` | 否 | 投放平台 |
| `tone` | 否 | 文案风格 |
| `language` | 否 | 输出语言 |
| `voice` | 否 | TTS 声音 ShortName |

响应体与 `/api/generate` 相同，并额外返回：

```json
{
  "image_keywords": ["补水", "锁水", "清爽"]
}
```

### 5.3 仅文案生成（v2，不含音频/字幕）

**`POST /api/v2/generate-copy`**

> 当 `AUTH_ENABLED=true` 时，需携带 `Authorization: Bearer <token>` 请求头。v2 轻量接口，仅生成文案正文，不合成 TTS 音频和 SRT 字幕，适用于只需要文案内容的场景。同时返回 LLM Token 用量统计。

请求体（JSON），使用 `CopyOnlyInput` 模型：

```json
{
  "category": "美妆",
  "title": "保湿面霜",
  "selling_points": ["补水", "锁水", "清爽不油腻"],
  "duration": 30,
  "platform": "抖音",
  "language": "zh",
  "tags": ["护肤", "秋冬"]
}
```

> **注意**：与 `/api/generate`（v1）不同，v2 接口**不需要** `tone`（风格）和 `voice`（音色）字段，风格固定为"简洁"。

响应体（CopyOnlyResponse）：

```json
{
  "input": { ... },
  "marketing_copy": {
    "title": "...",
    "tags": ["..."],
    "text": "...",
    "word_count": 120,
    "estimated_duration": 28.5
  },
  "skill_info": {
    "skill_name": "抖音_美妆_带货",
    "match_type": "exact",
    "matched_by": "抖音+美妆",
    "skill_description": "抖音美妆带货口播文案..."
  },
  "token_usage": {
    "prompt_tokens": 450,
    "completion_tokens": 320,
    "total_tokens": 770,
    "attempts": 1,
    "model": "deepseek-chat"
  },
  "image_keywords": null
}
```

### 5.4 图片模式仅文案生成（v2）

**`POST /api/v2/generate-copy/images`**

> 当 `AUTH_ENABLED=true` 时，需携带 `Authorization: Bearer <token>` 请求头。使用 `multipart/form-data`，先调用视觉模型提取关键词，再进入仅文案生成流程。

表单字段：

| 字段 | 必填 | 说明 |
|------|------|------|
| `category` | 是 | 产品品类 |
| `title` | 是 | 产品标题 |
| `images` | 是 | 商品图片，可多张，最多 6 张，单张不超过 8MB |
| `duration` | 否 | 目标文案时长，默认 30 |
| `platform` | 否 | 投放平台 |
| `language` | 否 | 输出语言 |

> **注意**：v2 图片接口也不包含 `tone` 和 `voice` 字段。

响应体与 `/api/v2/generate-copy` 相同，并额外返回 `image_keywords` 字段。

### 5.5 趋势数据摄入

**`POST /api/trends/douyin/videos`**

> 当配置了 `TREND_API_TOKEN` 时，需携带 `Authorization: Bearer <trend_api_token>` 请求头。用于接收抖音热门视频数据并存入趋势数据库，供文案生成时检索增强。

请求体（JSON）：

```json
{
  "items": [
    {
      "title": "...",
      "like_count": 50000,
      "share_count": 12000,
      "comment_count": 3000,
      "keyword": "...",
      "video_url": "..."
    }
  ]
}
```

响应体（JSON）：

```json
{
  "stats": {
    "total": 1,
    "inserted": 0,
    "updated": 1,
    "skipped": 0
  }
}
```

### 5.6 获取音频文件

**`GET /api/audio/{filename}`**

示例：`GET /api/audio/20260101_120000_audio.mp3`

### 5.7 获取字幕文件

**`GET /api/subtitle/{filename}`**

示例：`GET /api/subtitle/20260101_120000_subtitle.srt`

### 5.8 获取可用音色列表

**`GET /api/voices/{language}`**

示例：`GET /api/voices/zh`

响应体包含 `voices`（音色列表）和 `default`（默认音色）两个字段。

### 5.9 Token 管理（需启用认证）

> 以下接口仅在 `AUTH_ENABLED=true` 时有效，调用时需携带有效的 Authorization Header。

**`POST /api/token`** — 创建新 Token

请求头：`Authorization: Bearer <admin_token>`

请求体（JSON）：
```json
{
  "description": "测试 Token"
}
```

响应体（JSON）：
```json
{
  "token": "<生成的完整Token，仅此一次可见>",
  "description": "测试 Token"
}
```

**`GET /api/tokens`** — 获取所有 Token 列表（脱敏显示）

请求头：`Authorization: Bearer <admin_token>`

**`DELETE /api/token/{key}`** — 撤销（禁用）指定 Token

请求头：`Authorization: Bearer <admin_token>`

示例：`DELETE /api/token/abc123-def456`

## 6. 平台与品类支持

### 6.1 支持平台

| 平台 | 标识 | Skill 数量 | 适用场景 |
|------|------|------------|----------|
| 抖音 | `抖音` | 17 个 | 短视频带货口播 |
| 小红书 | `小红书` | 3 个 | 图文笔记/视频种草 |
| 淘宝 | `淘宝` | 1 个 | 商品详情页/直播 |
| TikTok | `TikTok` | 2 个 | 海外短视频带货 |

## 8. 高级功能说明

### 8.1 知识库增强

系统内置多平台 × 品类的参考文案库。生成时自动检索相关高赞文案，作为风格和结构参考。可通过环境变量控制：

```ini
ENABLE_KNOWLEDGE=true       # 启用知识库检索
MAX_KNOWLEDGE_REFS=3        # 最多引用 3 条参考文案
```

### 8.2 趋势知识增强

系统支持摄入抖音实时热门视频数据（通过 `/api/trends/douyin/videos` 接口），存入 SQLite 趋势数据库。生成文案时自动检索与当前产品相关的热门视频，提取品类、受众、场景、卖点关键词、转化方式等洞察，作为 Prompt 增强的一部分注入 LLM 上下文，提升文案的时效性和市场贴合度。可通过环境变量控制：

```ini
ENABLE_TREND_KNOWLEDGE=true         # 启用趋势知识增强
MAX_TREND_REFS=3                    # 最多引用 3 条趋势洞察
TREND_DB_PATH=data/trends.sqlite3   # 趋势数据库路径
TREND_API_TOKEN=                    # 趋势摄入 API 鉴权 Token
```

### 8.3 情感语音合成

系统自动分析文案的情感基调（感叹号密度、开头语气、结尾 CTA 等），实时调整 TTS 合成的 **语速（rate）** 和 **音调（pitch）**：

- 激动型文案：语速 +10%~15%，音调 +5~10Hz
- 平和型文案：保持默认
- 可通过 `EMOTION_ENABLED=false` 关闭此功能

### 8.4 价格智能约束

如果输入的产品信息中**未包含价格相关描述**，系统会自动约束 LLM，禁止在文案中虚构价格信息。

### 8.5 缩写词展开

TTS 合成前自动将英文缩写展开为可朗读的全称，例如：

| 缩写 | 展开 |
|------|------|
| ROI | return on investment |
| KOL | key opinion leader |
| OOTD | outfit of the day |
| CTA | call to action |

品牌名（如 MAC、NARS、SK-II、NIKE）不会被展开。

### 8.6 v2 仅文案 API（Token 用量统计）

v2 接口（`/api/v2/generate-copy`、`/api/v2/generate-copy/images`）专为只需要文案内容、无需音频和字幕的轻量场景设计。与 v1 的主要区别：

- 不生成 TTS 音频和 SRT 字幕，响应速度更快
- 返回 `token_usage` 字段，包含 `prompt_tokens`、`completion_tokens`、`total_tokens`、`attempts`、`model`，便于统计 LLM 调用成本
- 请求体无需 `tone`（风格）和 `voice`（音色）字段

### 8.7 字数智能控制

- 根据语种语速 + 情感语速修正估算目标字数
- 中/日/韩按字符计数，英文等按空格分词计数
- 生成结果超出目标 ±15% 时自动重试，最多 3 次

## 9. 常见问题

### Q1：启动时报错 "LLM_API_KEY not configured"

确保已创建 `.env` 文件并填入有效的 API Key：

```bash
cp .env.example .env
# 编辑 .env，填入真实 KEY
```

### Q2：生成文案很慢

文案生成耗时取决于 LLM 响应速度及是否触发重试。建议：

- 选择响应较快的模型（如 `deepseek-chat`）
- 设定合理的目标时长（不宜过短，如 15 秒以下）
- 确保网络连接稳定
- 若只需文案无需音频，使用 v2 `/api/v2/generate-copy` 接口

### Q3：TTS 合成失败

- 检查网络是否可访问微软 Edge TTS 服务
- 确保音色名称与选择语言匹配
- Windows 系统可能需要安装/更新 WebView2 运行时

### Q4：字幕与音频不同步

字幕基于 Edge-TTS 返回的词边界时间戳生成，正常情况下同步精准。如出现偏差，可能是网络波动导致部分时间戳丢失，重新生成即可。

### Q5：output 目录下文件越来越多

系统启动时和每次生成文案时，会自动清理 **超过 24 小时** 的旧文件，无需手动维护。

### Q6：如何批量生成文案？

使用 CLI 工具编写脚本：

```bash
# Windows batch 示例
python cli.py -c 美妆 -t "保湿面霜" -s "补水,锁水" -d 30 -p 抖音
python cli.py -c 数码 -t "蓝牙耳机" -s "降噪,长续航" -d 45 -p 抖音
python cli.py -c 食品 -t "坚果礼盒" -s "新鲜,营养" -d 25 -p 淘宝
```

### Q7：如何启用 API 认证？

在 `.env` 中设置 `AUTH_ENABLED=true`，重启服务后：
- 系统自动生成默认管理员 Token，打印在控制台
- Web 界面和 API 调用均需携带 `Authorization: Bearer <token>` 请求头
- 可通过 `POST /api/token` 创建更多 Token，`DELETE /api/token/{key}` 撤销 Token
- CLI 使用 `--token` 参数或 `AUTH_TOKEN` 环境变量传递 Token

### Q8：v1 和 v2 接口如何选择？

| 场景 | 推荐接口 |
|------|----------|
| 需要音频 + 字幕完整输出 | `/api/generate`（v1） |
| 只需要文案正文，需要统计 Token 用量 | `/api/v2/generate-copy`（v2） |
| 图片提取关键词 + 音频/字幕 | `/api/generate/images`（v1） |
| 图片提取关键词 + 仅文案 | `/api/v2/generate-copy/images`（v2） |

### Q9：如何自定义文案策略？

编辑 `app/skills/definitions/` 目录下的 Skill 定义文件，添加新的 `CopySkill` 实例并注册到 `SkillManager`。每个 Skill 可定制执行步骤、质量标准、禁用词、Prompt 模板等。
