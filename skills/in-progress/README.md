# In Progress

仍在开发中的 Skill。尚未准备好发布 —— 预期会有粗糙之处、破坏性变更和已放弃的实验。在它们毕业到稳定目录之前，不会被加入插件和顶层 README。

- **[review](./review/SKILL.md)** — 从两个平行维度审阅自某个固定点以来的变更：**Standards**（diff 是否符合仓库编码规范？）和 **Spec**（diff 是否忠实实现了原始 issue/PRD？）。
- **[writing-beats](./writing-beats/SKILL.md)** — 以 beat 旅程的方式构建文章，类似互动小说风格。选择一个起始 beat，只写那个 beat，然后转向下一个，直到文章自然结束。
- **[writing-fragments](./writing-fragments/SKILL.md)** — 通过深度访谈挖掘你的写作片段 —— 各种类型的写作素材 —— 并将它们追加到单个文档中，作为未来文章的原材料。
- **[writing-shape](./writing-shape/SKILL.md)** — 接收一份包含原材料的 markdown 文件，逐段将其塑造成一篇文章，每一步都论证格式选择。
