# Engineering

日常代码工作所使用的 Skills。

- **[copywriting-agent](./copywriting-agent/SKILL.md)** — 为短视频生成营销文案及对应的 TTS 口播脚本，支持多种风格和平台适配。
- **[diagnose](./diagnose/SKILL.md)** — 针对疑难 Bug 和性能回归的规范化诊断循环：复现 → 精简 → 假设 → 插桩 → 修复 → 回归测试。
- **[grill-with-docs](./grill-with-docs/SKILL.md)** — 通过深度追问环节检验你的方案是否与现有领域模型一致，打磨术语表达，并同步更新 `CONTEXT.md` 和 ADR。
- **[triage](./triage/SKILL.md)** — 通过基于状态机的分诊角色对 Issue 进行分级处理。
- **[improve-codebase-architecture](./improve-codebase-architecture/SKILL.md)** — 在代码库中发现深化机会，结合 `CONTEXT.md` 中的领域语言和 `docs/adr/` 中的架构决策。
- **[setup-matt-pocock-skills](./setup-matt-pocock-skills/SKILL.md)** — 为每个仓库搭建配置（Issue 追踪器、分诊标签词表、领域文档布局），供其他工程类 skill 消费。
- **[tdd](./tdd/SKILL.md)** — 测试驱动开发，遵循红-绿-重构循环。每次一个垂直切片来构建功能或修复 Bug。
- **[to-issues](./to-issues/SKILL.md)** — 将任意方案、规格或 PRD 拆解为可独立获取的 GitHub Issue，采用垂直切片方式。
- **[to-prd](./to-prd/SKILL.md)** — 将当前对话上下文转化为 PRD，并作为 GitHub Issue 提交。
- **[zoom-out](./zoom-out/SKILL.md)** — 让 agent 从更高维度审视代码，提供更广阔的上下文或更高层级的视角。
- **[prototype](./prototype/SKILL.md)** — 构建一次性原型来验证设计——既可以是用于验证状态/业务逻辑的可运行终端应用，也可以是在同一路由下切换的多个截然不同的 UI 变体。
