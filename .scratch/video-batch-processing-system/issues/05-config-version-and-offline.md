## 父 Issue

视频智能剪辑客户端 PRD（`.scratch/video-batch-processing-system/PRD.md`）

## 构建什么

在配置同步基础上，实现版本号检测更新机制和离线模式支持。

配置包含版本号字段，服务端变更时版本号递增。客户端连接时自动通过版本号检测是否有新配置，有则同步更新，避免冲突。

离线模式：仅能执行不依赖服务端 API 的操作（如本地视频剪辑）。需要服务端的操作（如文案生成、任务状态同步）超时后报错并标记任务失败。网络恢复后客户端重新拉取任务列表继续执行。

## 验收标准

- [ ] 配置包含版本号字段，服务端变更时版本号递增
- [ ] 客户端连接时自动检测版本号差异，有更新则同步
- [ ] 离线模式下可执行本地视频剪辑操作
- [ ] 离线模式下需要服务端的操作超时后报错并标记任务失败
- [ ] 网络恢复后自动重新拉取任务列表继续执行
- [ ] 版本号检测和离线切换记录日志
