## 构建什么

在重复检测模块基础上，实现自动重试机制。

当检测到视频重复时，任务管理模块自动触发重试流程。可配置重试次数（默认 3 次）。

参数扰动策略（重试时在原有参数基础上做显著偏移，而非完全随机）：
- 滤镜：切换到不同类别的滤镜
- 时长：在安全范围内做更大幅度的调整（±10%）
- 背景音乐：从列表中排除已使用过的音乐
- 文字样式：调整字体、颜色、位置至与原方案差异较大的组合

重试耗尽后标记任务失败并通知服务端。

## 验收标准

- [ ] 检测到重复时自动触发重试流程
- [ ] 重试次数可配置，默认 3 次
- [ ] 参数扰动策略：滤镜切换类别
- [ ] 参数扰动策略：时长 ±10% 调整
- [ ] 参数扰动策略：背景音乐排除已使用
- [ ] 参数扰动策略：文字样式差异最大化
- [ ] 重试耗尽标记任务失败并通知服务端
- [ ] 重试行为记录日志
