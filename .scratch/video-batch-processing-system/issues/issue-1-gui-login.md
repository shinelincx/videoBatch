## 构建什么

搭建 PySide6 桌面端主窗口框架，实现登录页、调用认证 API、Token 安全存储与自动刷新。这是整个桌面端的入口，后续所有 Issue 依赖于此。

端到端路径：启动桌面端 → 显示登录页 → 输入用户名密码 → 调用 `/api/auth/login` → 获取 Token → AES-256 加密本地存储 → 跳转用户面板占位页。

## 验收标准

- [ ] PySide6 主窗口框架启动正常，窗口标题"视频智能剪辑客户端"
- [ ] 登录页包含用户名输入框、密码输入框、"记住用户名"复选框、登录按钮
- [ ] 点击登录调用 `POST /api/auth/login`，成功则跳转到用户面板占位页
- [ ] 登录失败时以对话框显示服务端返回的错误信息
- [ ] 登录成功后将 Access Token + Refresh Token 以 AES-256 加密存储于本地配置目录
- [ ] 首次运行时自动生成随机 AES 加密密钥，存储于本地配置目录
- [ ] Token 自动刷新：Access Token 过期前 1 小时静默调用 `GET /api/auth/token` 刷新
- [ ] Refresh Token 过期后提示用户重新登录
- [ ] "记住用户名"勾选时明文存储用户名到本地配置文件，不存储密码
- [ ] 启动时若存在已存储的 Token 且未过期，自动跳转到用户面板
- [ ] 页面路由：登录页 ↔ 用户面板之间可正常切换

## 涉及 API

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/auth/login` | POST | 用户登录 |
| `/api/auth/token` | GET | 刷新 Token |
