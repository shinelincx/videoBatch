视频智能剪辑客户端 PRD（`.scratch/video-batch-processing-system/PRD.md`）

## 构建什么

实现从服务端接收任务列表并建立本地任务队列。调用 `/clip_record/pending_clip/list` 获取任务列表，每个任务包含任务 ID 和关联的素材 ID。

任务由服务端下发，客户端建立本地任务队列。支持任务优先级调度：默认按任务创建时间排序（先到先得），支持服务端指定优先级覆盖默认排序。

- [ ] 支持服务端指定优先级覆盖默认排序
