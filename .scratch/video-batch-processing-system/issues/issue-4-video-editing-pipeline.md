# Issue #4: 视频剪辑完整流水线

**标签**: `ready-for-agent`

**类型**: AFK

**被阻塞于**: #3

## 构建什么

实现完整的视频剪辑流水线：双模式基础视频生成（图生视频 + 原视频参考）、画面处理系列、叠加元素、后贴拼接、音频处理、重复拼接。全部通过 FFmpeg 命令行构建与执行，引入随机性参数以解决防重问题。

端到端路径：加载素材 → 基础视频生成（双模式）→ 画面处理 → 前后贴拼接 → 叠加元素（水印/字幕/弹幕/贴纸）→ 音频处理（背景音乐/语速/变调）→ 重复拼接（N 版本循环）→ 输出 `output.mp4`。

## 验收标准

### 基础视频生成
- [ ] **图生视频模式**：将 `img/` 目录中的单张或多张图片转换为视频（H.264/AAC/30fps）
- [ ] **原视频参考模式**：基于 `mv/reference.mp4` 生成视频；若配置了图片拼接，按 `image_duration` 将图片转视频片段，再按 `img_video_position`（before/after）与原视频参考拼接
- [ ] 原视频参考模式下，若 `img/` 目录为空或不存在，跳过拼接直接以原始参考视频进入后续处理
- [ ] 图生视频模式拼接原视频参考时，图生视频部分需缩放适配原视频参考的分辨率

### 画面处理（按顺序，所有操作引入随机性）
- [ ] 抽帧：在 5-20 帧范围内随机删除一帧
- [ ] 裁剪：在上下左右区域随机裁剪 1%-2% 画面
- [ ] 模糊：随机添加 1%-3% 模糊效果（FFmpeg boxblur）
- [ ] 抖动：添加 1%-3% 随机画面抖动效果（FFmpeg random + eq）
- [ ] 亮度：随机值范围 -0.2~0.2（FFmpeg eq）
- [ ] 对比度：随机值范围 0.5~1.5（FFmpeg eq）
- [ ] 饱和度：随机值范围 0.5~1.5（FFmpeg eq）
- [ ] 色彩平衡：RGB 随机值范围 -0.2~0.2（FFmpeg colorbalance）
- [ ] 伽马值：随机值范围 0.5~1.5（FFmpeg eq）
- [ ] 复古黑白：随机值范围 0.5~1.5（FFmpeg colorchannelmixer）

### 拼接处理
- [ ] 从 `metadata.json` 配置的目录中随机选择前贴视频拼接到视频前
- [ ] 从 `metadata.json` 配置的目录中随机选择后贴视频拼接到视频后

### 叠加元素
- [ ] 水印：从配置目录随机选取水印图片，10%-30% 随机透明度，随机运动轨迹
- [ ] 字幕：文字样式随机（字体/大小/颜色/位置在配置范围内随机）
- [ ] 弹幕：预设文本，字体/颜色/速度随机，密度由配置控制
- [ ] 贴纸：从配置目录随机选取，4 个角随机出现 1-4 个，10%-30% 随机透明度，小范围运动轨迹

### 音频处理
- [ ] 背景音乐：从 `metadata.json` 配置的音乐列表中随机选取，混音处理
- [ ] 语速调整：从本地配置文件获取随机值范围，执行时随机选取（FFmpeg atempo）
- [ ] 变调处理（可选）：若服务端配置启用，从本地配置文件随机半音数范围选值（如 -5~+5），通过 FFmpeg rubberband 实现

### 重复拼接
- [ ] 按配置的循环次数生成 N 个不同版本的视频并拼接为最终输出

### 随机性配置管理
- [ ] 随机化配置独立存储在客户端本地配置文件，定义各随机项取值范围
- [ ] 执行时根据服务端配置决定启用哪些随机选项
- [ ] 每次任务完成后将生成的随机值保存到任务日志 `logs/task_YYYY-MM-DD.log`
- [ ] 日志格式：`[时间戳] [任务ID] [模块] [级别] 消息`

### 异常处理
- [ ] FFmpeg 执行失败标记任务为 `failed`（不可恢复异常）
- [ ] 输出目录不存在时自动创建（`assets/output/{task_id}/`）
- [ ] 重试时覆盖同一输出文件，仅保留最终版本
