## 父 Issue

视频智能剪辑客户端 PRD（`.scratch/video-batch-processing-system/PRD.md`）

## 构建什么

实现客户端从服务端获取用户配置参数并本地缓存。调用 `/clip_config/config_map` 接口获取配置，配置项结构包含：剪辑模式（图生视频、原视频参考）、视频项（抽帧、裁剪、模糊、抖动、水印）、语音项（声音类型、语速、背景音乐）、文本项（字幕、弹幕）、前后贴（前贴视频、后贴视频）、重复（循环次数）。

配置仅作只读缓存，禁止本地修改。配置解析失败时回滚到上一版本，网络异常时使用缓存配置。

## 验收标准

- [ ] 调用 `/clip_config/config_map` 获取用户配置并缓存到 `config/user_config.json`
- [ ] 配置项结构完整解析（剪辑模式、视频项、语音项、文本项、前后贴、重复）
- [ ] 配置为只读，禁止本地修改
- [ ] 配置解析失败时回滚到上一版本
- [ ] 网络异常时使用缓存配置
- [ ] 关键流程节点记录日志
