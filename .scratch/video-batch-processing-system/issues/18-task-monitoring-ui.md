## 构建什么

实现可视化的任务监控界面，提供任务管理和状态监控能力。

界面需展示：
- 任务列表：显示所有任务的 ID、类型（图生视频/原视频参考）、当前状态
- 实时状态更新：任务状态变更时界面自动刷新
- 剪辑结果预览：已完成任务的视频可预览播放
- 错误提示：任务失败时显示错误原因
- 进度指示：处理中的任务显示当前执行步骤

此切片需要人工交互进行 UI 设计评审。
