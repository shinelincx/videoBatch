视频智能剪辑客户端 PRD（`.scratch/video-batch-processing-system/PRD.md`）

## 构建什么

在原视频参考模式（Issue #14）已实现的基础上，增加素材图片合并到参考视频的能力，以及素材缺失降级策略。

**素材图片合并（核心功能）**：
- 原视频参考模式下，将任务素材目录（`assets/{task_id}/img/`）中的图片素材先转换为视频片段，再与参考视频按配置位置合并为一个整体
- `img_video_position` 取值：
  - `"before"`：图片生成的视频片段拼接在参考视频之前
  - `"after"`：图片生成的视频片段拼接在参考视频之后
- 合并后得到一个完整的基础视频，作为后续画面处理步骤的输入

**图片播放时长**：
- 素材目录中的每张图片独立转换为视频片段，每张图片的展示时长由服务端配置参数决定（如 `image_duration` 字段，单位秒）
- 所有图片使用统一的展示时长（同一配置值应用于该任务中的所有图片）
- 多张图片按文件名排序依次拼接为一段连续的图片视频，再与参考视频合并

**降级策略**：
- 原视频参考模式下，若素材图片目录（`img/`）为空或不存在，则跳过图片视频拼接步骤，直接以原始参考视频进入后续画面处理流程
- 降级不是任务失败：降级后任务仍可继续执行后续所有步骤
- 降级发生时记录 WARNING 级别日志，标明任务 ID、缺失路径、降级原因

## 验收标准

- [ ] 原视频参考模式 + `img_video_position` 为 `"before"`，图片视频拼接在参考视频之前，输出正确
- [ ] 原视频参考模式 + `img_video_position` 为 `"after"`，图片视频拼接在参考视频之后，输出正确
- [ ] 每张图片的展示时长由服务端配置参数决定，多张图片按序拼接
- [ ] 图片素材目录为空或不存在时，跳过图片视频拼接，降级为原始参考视频继续后续处理
- [ ] 降级时记录 WARNING 级别日志（任务 ID、缺失路径、降级原因）
- [ ] 降级后任务不被标记为失败，后续处理步骤正常执行
- [ ] 拼接后的基础视频输出到 `assets/output/{task_id}/output_stage1.mp4`
- [ ] 图片视频片段与参考视频编码格式/分辨率不一致时自动转码对齐
- [ ] 关键流程节点记录日志
