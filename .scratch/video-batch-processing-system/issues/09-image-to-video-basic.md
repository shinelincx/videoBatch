## 父 Issue

视频智能剪辑客户端 PRD（`.scratch/video-batch-processing-system/PRD.md`）

## 构建什么

实现图生视频模式的基础输出能力。将单张或多张图片素材转换为视频，输出格式为 H.264 视频编码 + AAC 音频编码，分辨率保持与输入素材一致，帧率 30fps。

这是视频剪辑模块的第一个垂直切片，端到端贯穿：从素材管理获取图片 → FFmpeg 编码生成视频 → 输出到 `assets/output/{task_id}/output.mp4`。

FFmpeg 执行失败标记任务失败（不可恢复异常），输出路径不存在自动创建。

## 验收标准

- [ ] 单张图片可转换为视频输出
- [ ] 多张图片可拼接转换为视频输出
- [ ] 输出格式：H.264 视频编码 + AAC 音频编码
- [ ] 分辨率保持与输入素材一致
- [ ] 帧率 30fps
- [ ] 输出视频时长由服务端配置参数决定（图生视频模式下图片无固有时长，需从配置中获取每张图片的展示时长）
- [ ] 输出到 `assets/output/{task_id}/output.mp4`
- [ ] FFmpeg 执行失败标记任务失败
- [ ] 输出路径不存在自动创建
- [ ] 关键流程节点记录日志
