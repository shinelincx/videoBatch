## 父 Issue

视频智能剪辑客户端 PRD（`.scratch/video-batch-processing-system/PRD.md`）

## 构建什么

将贴纸叠加功能挂入视频剪辑流水线的叠加元素步骤，并编写模块测试与集成测试。

端到端行为：
1. 贴纸叠加在叠加元素步骤中执行，位于弹幕效果之后、文案与音频生成之前
2. 贴纸叠加由服务端配置开关控制（与弹幕、水印同属一组随机化叠加元素）
3. 模块测试：验证贴纸选取、位置分布、透明度范围、运动轨迹等独立行为
4. 集成测试：验证贴纸叠加在图生视频和原视频参考两种模式下均正常工作
