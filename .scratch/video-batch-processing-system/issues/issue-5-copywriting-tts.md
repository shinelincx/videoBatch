# Issue #5: 文案生成 + TTS 音频替换

**标签**: `ready-for-agent`

**类型**: AFK

**被阻塞于**: #1

---

## 构建什么

当配置启用营销文案时，调用 AI 接口生成文案，再通过 TTS 转换为语音文件，替换素材中的原始音频。此功能可选，由服务端配置控制是否启用。

端到端路径：检查配置是否启用文案 → 调用 `/api/copywriting` 生成营销文案 → 调用 TTS 接口将文案转语音 → 生成的音频文件替换素材中的原始音频轨道。

## 验收标准

- [ ] 检查服务端配置中是否启用营销文案需求，非用户手动开关
- [ ] 调用 `POST /api/copywriting` 生成营销文案（支持产品介绍/促销活动/情感文案等类型）
- [ ] 支持文案风格配置：幽默、正式、亲切、悬疑等
- [ ] 调用 TTS 接口将文案转换为语音文件，保存到 `temp/audio/` 目录
- [ ] 使用 FFmpeg 将 TTS 音频替换视频中的原始音频轨道
- [ ] AI 接口调用失败时任务标记为 `failed`
- [ ] 音频生成失败时任务标记为 `failed`
- [ ] 任务完成后清理 `temp/audio/` 中的临时音频文件

## 涉及 API

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/copywriting` | POST | 生成营销文案 |
