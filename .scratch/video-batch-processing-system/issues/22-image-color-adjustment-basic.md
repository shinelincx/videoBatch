## 父 Issue

视频智能剪辑客户端 PRD（`.scratch/video-batch-processing-system/PRD.md`）

## 构建什么

在图生视频和原视频参考两种模式的画面处理步骤中，实现亮度、对比度、饱和度三项基础色彩调整效果，全部通过 FFmpeg `eq` 滤镜统一处理，所有操作引入随机性以解决防重问题。

端到端行为：
1. 画面处理步骤中，在抖动处理之后新增色彩调整子步骤
2. 三项处理（亮度/对比度/饱和度）均通过 FFmpeg `eq` 滤镜实现，在一次滤镜调用中完成
3. 亮度：随机值通过本地配置文件设置 -0.2 到 0.2
4. 对比度：随机值通过本地配置文件设置 0.5 到 1.5
5. 饱和度：随机值通过本地配置文件设置 0.5 到 1.5
6. 随机值从本地配置文件（随机化配置）读取范围，每次任务生成随机值
7. 任务完成后将生成的随机值写入任务日志
8. 所有处理项由服务端配置开关控制是否启用

## 验收标准

- [ ] 亮度设置：随机值在 -0.2 到 0.2 范围内，通过 FFmpeg `eq=brightness=...` 实现
- [ ] 对比度设置：随机值在 0.5 到 1.5 范围内，通过 FFmpeg `eq=contrast=...` 实现
- [ ] 饱和度设置：随机值在 0.5 到 1.5 范围内，通过 FFmpeg `eq=saturation=...` 实现
- [ ] 三项处理合并为一次 FFmpeg `eq` 滤镜调用，避免重复编码
- [ ] 随机化配置独立存储在本地配置文件中，定义各随机项取值范围
- [ ] 根据服务端配置参数决定启用哪些随机选项
- [ ] 每次任务完成后随机值保存到任务日志
- [ ] 支持配置参数动态调整，无需重启
- [ ] 随机参数范围不影响用户观感
- [ ] 图生视频和原视频参考两种模式均适用
- [ ] 关键流程节点记录日志
