## 父 Issue

视频智能剪辑客户端 PRD（`.scratch/video-batch-processing-system/PRD.md`）

## 构建什么

在图生视频和原视频参考两种模式的画面处理步骤中，实现色彩平衡、伽马值、复古黑白三项高级色彩效果处理，均引入随机性以解决防重问题。

端到端行为：
1. 画面处理步骤中，在基础色彩调整之后新增高级色彩效果子步骤
2. 色彩平衡设置：对红、绿、蓝三通道分别添加随机偏移，随机值通过本地配置文件设置 -0.2 到 0.2，通过 FFmpeg `colorbalance` 滤镜实现
3. 伽马值设置：随机添加伽马值处理效果，随机值通过本地配置文件设置 0.5 到 1.5，通过 FFmpeg `eq=gamma=...` 实现
4. 复古黑白设置：随机添加复古黑白处理效果，随机值通过本地配置文件设置 0.5 到 1.5，通过 FFmpeg `hue=s=0` + `curves` 组合实现
5. 随机值从本地配置文件（随机化配置）读取范围，每次任务生成随机值
6. 任务完成后将生成的随机值写入任务日志
7. 所有处理项由服务端配置开关控制是否启用
