**类型**: AFK

**被阻塞于**: #1

## 构建什么

实现用户面板完整页面，包括素材根目录配置区、任务列表表格、重复检测列展示，以及素材/视频查看功能。用户面板是登录后的主操作界面。

端到端路径：登录成功 → 用户面板 → 配置素材根目录 → 调用 `GET /clip_record/pending_clip/list` 获取任务列表 → 表格展示 → 按状态筛选 → 点击行查看素材/视频。

## 验收标准

### 素材根目录配置
- [ ] 提供输入框 + "浏览"按钮（目录选择器），允许用户配置本地素材根目录绝对路径
- [ ] 配置保存到本地配置文件，下次启动自动加载并显示
- [ ] 修改后立即生效，无需重启

### 任务列表表格
- [ ] 调用 `GET /clip_record/pending_clip/list` 获取任务列表并在表格中展示
- [ ] 表格列：任务ID、素材ID、配置ID、任务状态、重复检测
- [ ] 支持按状态筛选下拉框（全部 / 待处理 / 处理中 / 重试中 / 已完成 / 失败）
- [ ] 手动刷新按钮，点击重新调用 `GET /clip_record/pending_clip/list`
- [ ] 任务状态变更时表格自动更新显示

### 重复检测列
- [ ] 显示最近一次重复检测的汉明距离
- [ ] 若汉明距离 > 相似度阈值（默认12），标记为"通过"
- [ ] 若汉明距离 ≤ 阈值，显示实际数值
- [ ] 若尚未进行重复检测，显示"-"

### 素材/视频查看
- [ ] 点击任务行的"素材查看"按钮，以独立窗口播放该任务关联的素材文件（所有状态均可查看）
- [ ] 点击任务行的"视频查看"按钮，以独立窗口播放已生成的视频（仅在 `completed` 或 `failed` 状态可用）
- [ ] 素材/视频不存在时给出提示

## 涉及 API

| 接口 | 方法 | 说明 |
|------|------|------|
| `/clip_record/pending_clip/list` | GET | 获取任务列表 |
