## 简介

抖音自动发布工具是一个基于 Playwright 的自动化脚本，用于自动发布视频到抖音创作者中心。该工具支持定时发布、隐私设置和批量发布功能，能够帮助用户高效地管理抖音内容发布工作流。

## 环境准备

### Node.js 环境要求

在开始之前，请确保您的系统满足以下要求：

- **Node.js 版本**: 必须安装 Node.js 18 或更高版本
- **操作系统**: 支持 Windows、macOS 和 Linux
- **内存**: 建议至少 4GB RAM
- **网络**: 需要稳定的互联网连接

### 验证 Node.js 安装

在终端中运行以下命令验证 Node.js 安装：

```bash
node --version
npm --version
```

预期输出：
```
v18.x.x
9.x.x
```

## 安装步骤

### 1. 创建项目目录

```bash
mkdir douyin-auto-publisher
cd douyin-auto-publisher
```

### 2. 初始化 npm 项目

```bash
npm init -y
```

### 3. 安装 Playwright 依赖

```bash
npm install playwright
```

### 4. 安装 Chromium 浏览器

```bash
npx playwright install chromium
```

### 5. 验证安装

运行以下命令确认安装成功：

```bash
npx playwright --version
```

预期输出：
```
Playwright CLI version: 1.60.0
Playwright version: 1.60.0
```

```json
  }

```

#### 主要配置项

在 `douyin-publish.js` 文件中，您需要配置以下关键参数：

```javascript
const CONFIG = {
  // 视频文件夹路径 - 修改为您实际的视频存储位置
  videoDir: 'D:\\test',
  
  // 作品主题 - 视频标题
  topicTitle: '这是一个水',
  
  // 作品描述 - 视频内容描述
  description: '这是一个水瓶',
  
  // 谁可以看 - 隐私设置
  visibility: '仅自己可见',
  
  // 定时发布时间 - 格式: YYYY-MM-DD HH:mm
  scheduledTime: null, // null 表示自动计算为明天10:00
  
  // 抖音创作者中心URL
  creatorHomeUrl: 'https://creator.douyin.com/creator-micro/home',
  
  // 发布页面URL
  publishUrl: 'https://creator.douyin.com/creator-micro/content/upload',
  
  // 是否显示浏览器界面
  headless: false,
  
  // 操作间隔（毫秒）
  actionDelay: 1000,
};
```

## 使用方法

### 1. 准备视频文件

在配置的 `videoDir` 路径下放置要发布的视频文件。支持的格式包括：
- `.mp4` - 推荐格式
- `.mov` - QuickTime 格式
- `.avi` - AVI 格式
- `.mkv` - MKV 格式
- `.flv` - Flash Video
- `.wmv` - Windows Media Video
- `.webm` - WebM 格式

### 2. 配置发布参数

根据需要修改 `douyin-publish.js` 文件中的 CONFIG 对象：

```javascript
const CONFIG = {
  videoDir: 'D:\\test',           // 修改为您的视频文件夹路径
  topicTitle: '我的新视频',       // 修改为视频标题
  description: '这是视频描述',   // 修改为视频描述
  visibility: '仅自己可见',       // 隐私设置
  scheduledTime: null,           // 定时发布时间
  headless: false,               // 显示浏览器界面
  actionDelay: 1000              // 操作延迟
};
```

### 3. 运行发布脚本

使用以下命令启动发布流程：

```bash
npm run publish
```

或者直接运行：

```bash
node douyin-publish.js
```

### 4. 发布流程详解

脚本执行的主要步骤：

1. **启动浏览器**: 自动启动 Chromium 浏览器
2. **登录验证**: 检测是否需要手动登录
3. **进入发布页面**: 导航到抖音创作者中心
4. **上传视频**: 选择并上传视频文件
5. **填写描述**: 自动填写标题和描述
6. **设置隐私**: 配置可见性设置
7. **定时发布**: 设置发布时间
8. **确认发布**: 用户确认后执行发布

## 故障排除

### 常见问题及解决方案

#### 1. Node.js 版本不兼容

**问题**: 安装 Playwright 时报错，提示 Node.js 版本过低

**解决方案**:
```bash
# 检查当前版本
node --version

# 如果版本低于 18，需要升级 Node.js
# 从 https://nodejs.org 下载最新 LTS 版本
```

#### 2. Playwright 安装失败

**问题**: `npm install playwright` 执行失败

**解决方案**:
```bash
# 清理缓存
npm cache clean --force

# 删除 node_modules 和 package-lock.json
rm -rf node_modules package-lock.json

# 重新安装
npm install playwright

# 安装浏览器
npx playwright install chromium
```

#### 3. 浏览器无法启动

**问题**: 脚本启动后浏览器无法正常加载

**解决方案**:
```bash
# 检查浏览器安装
npx playwright install-deps

# 更新 Playwright 到最新版本
npm update playwright

# 检查防火墙设置
```

#### 4. 视频文件找不到

**问题**: 程序提示找不到视频文件

**解决方案**:
```javascript
// 确保路径正确
const CONFIG = {
  videoDir: 'D:\\test',  // 使用绝对路径
  // 或者使用相对路径
  // videoDir: './videos'
};

// 检查文件是否存在
console.log('视频文件夹:', fs.existsSync(CONFIG.videoDir));
```

#### 5. 登录问题

**问题**: 自动登录失败或需要手动登录

**解决方案**:
```javascript
// 在 CONFIG 中设置 headless: false 来查看登录过程
const CONFIG = {
  headless: false,  // 显示浏览器界面
  actionDelay: 2000 // 增加操作延迟
};
```

#### 6. 发布按钮点击失败

**问题**: 自动点击发布按钮失败

**解决方案**:
```javascript
// 手动确认发布
console.log('请手动点击发布按钮');
await new Promise(resolve => {
  process.stdin.once('data', () => resolve());
});
```

- **命名规范**: 使用有意义的文件名，避免特殊字符
- **格式优化**: 优先使用 MP4 格式，编码质量适中

### 3. 发布策略

- **内容规划**: 制定内容发布计划，保持更新频率
- **时间安排**: 选择合适的发布时间，提高内容曝光率
- **效果监控**: 定期检查发布效果，调整策略

- **账号安全**: 不要在公共计算机上保存登录凭据
- **隐私保护**: 避免发布敏感信息

### 5. 性能优化

- **资源管理**: 合理配置浏览器资源使用
- **错误处理**: 完善的错误处理机制
- **日志记录**: 详细的日志记录便于问题排查
